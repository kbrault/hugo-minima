# hugo-minima

A minimal Hugo theme replicating the classic Jekyll "Minima" v1 template.

## Structure

```
layouts/          templates
static/css/       stylesheet
static/img/       header image + icons
content/posts/    blog posts
archetypes/       `hugo new posts/my-post.md`
```

## Config

```toml
[params]
  description = "Description of the site"
  intro       = "The home block"
```
